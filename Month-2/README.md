# 📊 E-Commerce Sales Overview & Customer Value Analysis Dashboard

## 📌 Overview

This project analyzes e-commerce sales performance and customer purchasing behavior using the **Brazilian E-Commerce Public Dataset by Olist**.

An interactive **Power BI dashboard** was developed to transform raw e-commerce data into meaningful business insights through data cleaning, transformation, data modeling, DAX, and visualization.

---

## 🎯 Objectives

- Analyze overall sales and order performance
- Understand customer purchasing behavior
- Identify premium and high-value customers
- Analyze payment methods and installment behavior
- Understand customer review patterns
- Compare order volume across Brazilian states
- Analyze customer payment-value contribution
- Explore geographic and customer-level trends
- Build an interactive dashboard for business analysis

---

## 🗂️ Dataset

The project uses the **Brazilian E-Commerce Public Dataset by Olist**.

**Dataset Source:**  
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains information related to:

- Orders

- Customers

- Sellers

- Payments

- Products

- Reviews

- Geographic locations

- Order dates and delivery information

## 📊 Dashboard

The dashboard consists of two analytical pages designed to provide an overview of e-commerce performance and customer value.

### 🛒 Page 1 – E-Commerce Sales Overview

This page provides an overview of overall e-commerce performance.

**Key Analysis Areas:**

- Total orders and revenue
- Average order value
- Average review score
- Seller performance by city
- Payment method distribution
- Geographic distribution of sellers
- Overall sales and transaction patterns

---

### 👥 Page 2 – Customer Value Analysis

This page focuses on customer purchasing behavior and customer value.

**Key Analysis Areas:**

- Average customer purchases
- Total payment value
- Premium customer analysis
- High-value customer analysis
- Customer review distribution
- Payment installment behavior
- Top customer states by order volume
- Customer payment-value contribution
